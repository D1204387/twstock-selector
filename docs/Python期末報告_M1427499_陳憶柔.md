## 1. 專案動機與目標

### 1.1 問題背景

台灣股票市場擁有超過 **2,000 檔**上市櫃股票與 ETF，投資人面臨嚴重的「資訊過載」問題：

- 財務資料分散在各大財經網站
- 手動比較多檔股票耗時費力
- 缺乏統一的篩選與評分標準

### 1.2 專案目標

開發一套 **智慧選股系統**，達成以下目標：

| 目標 | 說明 |
|------|------|
| 🔍 資料整合 | 整合 FinMind API 真實財務資料 |
| 📊 智慧評分 | 依據財務指標自動評分（0-10 分） |
| 🎛️ 策略篩選 | 提供成長股、價值股、高股息等策略 |
| 🤖 AI 選股 | 支援自然語言查詢選股 |
| ⚡ 離線優先 | Offline-First 架構，零延遲瀏覽 |

def calculate_score(df: pd.DataFrame, weights: Dict = None):
    # 計算各指標分數
    df['roe_score'] = df['roe'].apply(score_roe)
    df['pe_score'] = df['pe'].apply(score_pe)
    df['pb_score'] = df['pb'].apply(score_pb)
    df['debt_score'] = df['debt_ratio'].apply(score_debt_ratio)
    
    # 加權計算
    df['score'] = (

#### Streamlit 快取機制

## 7. 程式碼範例

### 7.1 股票評分計算

```python
# src/stock_analyzer.py

def score_roe(roe: float) -> float:
    """ROE 評分函數
    
    極端值處理：
    - ROE < -50%：嚴重虧損，給 0 分
    - ROE < 0%：虧損，給 0 分
    - ROE > 60%：可能為一次性獲利，仍給滿分但需警示
    """
    if pd.isna(roe):
        return 5.0
    if roe < 0:
        return 0.0
    if roe >= 25:
        return 10.0
    return round(roe / 25 * 10, 1)


def score_pe(pe: float) -> float:
    """PE 評分函數"""
    if pd.isna(pe) or pe <= 0:
        return 0.0
    if 10 <= pe <= 20:
        return 10.0  # 理想區間
    if pe < 10:
        # PE 太低可能有風險
        return 7.0 + (pe / 10) * 3
    if pe <= 30:
        return 10 - (pe - 20) / 10 * 5
    return 2.0  # PE > 30 偏貴


def score_pb(pb: float) -> float:
    """PB 評分函數"""
    if pd.isna(pb) or pb <= 0:
        return 5.0
    if pb <= 1:
        return 10.0
    if pb <= 2:
        return 10 - (pb - 1) * 3
    if pb <= 3:
        return 7 - (pb - 2) * 4
    return max(0, 3 - (pb - 3))
```

### 7.2 策略篩選

```python
# src/stock_screener.py

def apply_conditions(df: pd.DataFrame, conditions: Dict) -> pd.DataFrame:
    """根據條件篩選股票
    
    Args:
        df: 股票資料 DataFrame
        conditions: 條件字典，格式如 {'roe': {'min': 15, 'max': None}}
    
    Returns:
        符合條件的股票 DataFrame
    """
    result = df.copy()
    
    for indicator, cond in conditions.items():
        if indicator not in result.columns:
            continue
        
        min_val = cond.get('min')
        max_val = cond.get('max')
        
        if min_val is not None:
            result = result[result[indicator] >= min_val]
        
        if max_val is not None:
            result = result[result[indicator] <= max_val]
    
    return result
```

### 7.3 自然語言解析

```python
# src/ai_query.py

def parse_query_fallback(query: str) -> Dict:
    """關鍵字匹配備用方案（不需要 API）"""
    
    filters = {}
    strategy = None
    explanation = ""
    
    # 策略關鍵字
    if '成長' in query:
        strategy = 'growth'
        explanation = '篩選成長潛力股'
    elif '價值' in query or '便宜' in query:
        strategy = 'value'
        explanation = '篩選被低估的價值股'
    elif '股息' in query or '配息' in query or '殖利率' in query:
        strategy = 'dividend'
        explanation = '篩選高股息股票'
    elif '優質' in query or '穩健' in query:
        strategy = 'quality'
        explanation = '篩選財務穩健的優質股'
    
    # 數值條件解析
    patterns = [
        (r'ROE.*?(\d+)', 'roe'),
        (r'PE.*?(\d+)', 'pe'),
        (r'殖利率.*?(\d+)', 'dividend_yield'),
    ]
    
    for pattern, indicator in patterns:
        match = re.search(pattern, query, re.IGNORECASE)
        if match:
            value = float(match.group(1))
            filters[indicator] = {'min': value}
    
    return {
        'filters': filters,
        'strategy': strategy,
        'explanation': explanation
    }
```
