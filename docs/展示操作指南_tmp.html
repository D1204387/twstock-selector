台股智選系統 - 展示操作指南

系統啟動

# 1. 進入專案目錄
cd /Users/yijouchen/Developer/Python2025/twstock-selector

# 2. 啟動系統
streamlit run main.py

瀏覽器將自動開啟 http://localhost:8501

展示流程（約 10-15 分鐘）

第一步：首頁概覽（2 分鐘）

展示重點：

  • 系統名稱與核心特色
  • 四大投資策略卡片（成長潛力、價值股、高股息、優質股）
  • 即時數據更新時間
  • 11 項財務指標統計

操作：

  1. 展示首頁的策略卡片
  2. 點擊任一策略進入詳情

第二步：搜尋功能（3 分鐘）

路徑：側邊欄 → 🔍 搜尋

展示案例 1：優質股票 - 台積電

  1. 在搜尋框輸入 2330 或 台積電
  2. 展示評分卡片（分數 + 等級）
  3. 展示五角雷達圖（ROE、PE、PB、負債率、殖利率）
  4. 展開「獲利能力」查看 ROE、淨利率等指標

展示案例 2：高股息 ETF - 元大高股息

  1. 搜尋 0056
  2. 展示 ETF 專屬雷達圖（殖利率、折溢價、配息穩定度、分散風險、追蹤效率）
  3. 說明 ETF 使用不同的評分邏輯

展示案例 3：虧損公司（可選）

  1. 搜尋 1301 台塑（若 ROE 為負）
  2. 展示紅色警示橫幅
  3. 說明系統會自動標記異常值

第三步：智慧篩選（2 分鐘）

路徑：側邊欄 → 🎛️ 篩選

操作：

  1. 設定 ROE ≥ 15%
  2. 設定 PE 10-20
  3. 設定負債率 ≤ 50%
  4. 點擊「開始篩選」
  5. 查看符合條件的股票清單

重點說明：

  • 條件可自由組合
  • 即時顯示篩選結果數量

第四步：排名系統（2 分鐘）

路徑：側邊欄 → 🏆 排名

操作：

  1. 展示 Top 20 股票排名
  2. 切換到「ETF 排名」Tab
  3. 點擊「📥 匯出 CSV」下載報表

重點說明：

  • 評分權重：ROE 40% + PE 30% + PB 15% + 負債率 15%
  • ETF 評分：殖利率 70-80% + PB/配息年數 20-30%

第五步：AI 智慧選股（3 分鐘）

路徑：側邊欄 → 🤖 AI 智慧選股

展示案例：

輸入 預期結果
ROE 大於 20 的股票 高獲利能力股票
殖利率超過 5% 高股息股票
本益比低於 15 且 ROE 大於 15 價值成長股

操作：

  1. 輸入自然語言查詢
  2. 展示解析結果（系統如何理解查詢）
  3. 查看篩選結果表格
  4. 點擊「📥 匯出 CSV」下載

技術亮點說明

1. 資料來源

  • FinMind API 取得真實財務數據
  • 120 檔核心股票（台灣 50 + 中型 100 + 熱門 ETF）
  • 7 次 API 請求/股票，確保 11 項指標完整

2. 評分系統

一般股票：ROE (40%) + PE (30%) + PB (15%) + 負債率 (15%)
ETF：    殖利率 (70-80%) + PB/配息年數 (20-30%)

3. 智慧處理

  • 自動識別 ETF 並切換評分模式
  • 金融股財報欄位自動適配
  • 虧損公司視覺警示

4. 測試覆蓋

  • 45 個單元測試全數通過
  • 涵蓋評分函數、整合測試、篩選邏輯

常見問題

Q: 資料多久更新一次？ A: 目前使用快取資料，可執行 python scripts/robust_download.py 重新下載

Q: 為什麼有些 ETF 沒有 PE/PB？ A: ETF 結構與一般股票不同，系統自動使用備案評分邏輯

Q: 如何新增追蹤股票？ A: 編輯 src/finmind_api.py 中的 CORE_STOCKS 清單
