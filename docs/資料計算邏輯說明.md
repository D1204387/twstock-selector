本文件詳細說明「台股智選系統」如何從 FinMind API 取得原始數據，並透過 Python 進行資料清洗與財務指標計算。

## 1. 資料來源策略 (Data Strategy)

系統採用 **完整版資料抓取函數 `fetch_indicators_full`**，每檔股票進行 **7 次 API 請求**，確保 11 項指標完整：

| # | 資料集 | 取得欄位 |
| :--- | :--- | :--- |
| 1 | `TaiwanStockPER` | PE, PB, 殖利率 |
| 2 | `TaiwanStockPrice` | 收盤價 |
| 3 | `TaiwanStockDividend` | 配息年數（計算連續配息）|
| 4 | `TaiwanStockFinancialStatements` (今年) | EPS, 淨利, 營收, 毛利, 營業利益 |
| 5 | `TaiwanStockFinancialStatements` (去年) | 去年 EPS（計算成長率）|
| 6 | `TaiwanStockBalanceSheet` | 總資產, 負債, 權益 |
| 7 | `TaiwanStockMonthRevenue` | 月營收（計算 YoY 成長率）|

## 3. 間接數據與計算邏輯 (Indirect Data & Algorithms)

### 3.1 ROE (股東權益報酬率)

由財報與資產負債表推算：

> **公式**： $ROE = \frac{\text{本期淨利}}{\text{權益總額}} \times 100\% \times 4$ (年化)

```python
# 取得原始數據
net_income = raw_data['NetIncome']  # from FinancialStatements: IncomeAfterTax(es)
equity = raw_data['Equity']         # from BalanceSheet: EquityAttributableToOwnersOfParent

if net_income and equity and equity != 0:
    roe = (net_income / equity) * 100 * 4  # 年化
    if -100 <= roe <= 100:  # 合理性檢查
        result['roe'] = round(roe, 2)
```

### 3.2 ROA (資產報酬率)

```python
if net_income and total_assets and total_assets != 0:
    roa = (net_income / total_assets) * 100 * 4  # 年化
    if -50 <= roa <= 50:
        result['roa'] = round(roa, 2)
```

### 3.3 負債率 (Debt Ratio)

```python
if total_liabilities and total_assets and total_assets != 0:
    result['debt_ratio'] = round((total_liabilities / total_assets) * 100, 2)
```

### 3.4 獲利能力三率

利用營收作為分母計算：

*   **毛利率** = `GrossProfit / Revenue × 100%`
*   **營業利益率** = `OperatingIncome / Revenue × 100%`
*   **淨利率** = `IncomeAfterTax / Revenue × 100%`

```python
if raw_data['Revenue'] and raw_data['Revenue'] != 0:
    if raw_data['NetIncome']:
        result['net_profit_margin'] = round((raw_data['NetIncome'] / raw_data['Revenue']) * 100, 2)
    if raw_data['GrossProfit']:
        result['gross_margin'] = round((raw_data['GrossProfit'] / raw_data['Revenue']) * 100, 2)
    if raw_data['OperatingIncome']:
        result['operating_margin'] = round((raw_data['OperatingIncome'] / raw_data['Revenue']) * 100, 2)
```

### 3.5 配息年數 (Dividend Years)

計算連續配息年數（從當前年往回追溯）：

```python
current_year = datetime.now().year
consecutive_years = 0
for y in range(current_year - 1, current_year - 20, -1):
    if y in years_with_dividend:
        consecutive_years += 1
    else:
        break
result['dividend_years'] = consecutive_years
```

### 3.6 EPS 成長率

比較今年與去年同季的 EPS：

```python
if current_eps and last_eps and abs(last_eps) > 0.01:
    result['eps_growth'] = round(((current_eps - last_eps) / abs(last_eps)) * 100, 2)
```

## 4. 金融股特殊處理

金融業財報結構與一般產業不同：

| 欄位 | 一般產業 | 金融業 |
| :--- | :--- | :--- |
| 淨利 | `IncomeAfterTaxes` | `IncomeAfterTax` |
| 毛利率 | ✅ 適用 | ❌ 不適用（無毛利概念）|
| 營業利益率 | ✅ 適用 | ❌ 不適用 |

```python
# 統一處理：使用部分匹配
if 'incomeaftertax' in item_type and 'non' not in item_type:
    raw_data['NetIncome'] = val
```
