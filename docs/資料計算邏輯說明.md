# Python 實作：金融數據計算邏輯說明

本文件詳細說明「台股智選系統」如何從 FinMind API 取得原始數據，並透過 Python 進行資料清洗與財務指標計算。這套邏輯確保了即便 API 欄位變動或缺漏，系統仍能維持高準確度。

## 1. 資料來源策略 (Data Strategy)

系統採用混合式資料處理策略：
*   **直接數據 (Direct Data)**：API 已計算好的指標，直接使用。
*   **間接數據 (Indirect Data)**：API 僅提供原始會計科目，需自行撰寫演算法計算比率 (如 ROE)。

---

## 3. 間接數據與計算邏輯 (Indirect Data & Algorithms)

由於 API 在財報資料集 (`TaiwanStockFinancialStatements`) 中未直接提供部分比率，我們需抓取原始會計數據進行 Python 手動計算。

### 3.1 原始會計科目擷取

程式碼會從財報中篩選出以下原始值 (`Raw Data`)：

*   **本期淨利 (Net Income)**：對應 `IncomeAfterTaxes` (已排除少數股權)
*   **權益總額 (Equity)**：對應 `EquityAttributableToOwnersOfParent`
*   **營收 (Revenue)**：對應 `Revenue`
*   **毛利 (Gross Profit)**：對應 `GrossProfit`
*   **營業利益 (Operating Income)**：對應 `OperatingIncome`

### 3.2 核心演算法：ROE (股東權益報酬率)

為了確保 ROE 數據的絕對穩健，我們設計了 **雙重計算策略 (Dual-Strategy Approach)**：

#### 策略 A：PB/PE 推算法 (優先採用)
利用數學恆等式進行推算，此法最為穩定，因為 PE 與 PB 通常由交易所直接提供，較少缺漏。
> **公式**： $ROE = \frac{EPS}{NAV} = \frac{Price / PE}{Price / PB} = \frac{PB}{PE}$

```python
# 程式實作範例 (src/finmind_api.py)
if result['pe'] and result['pb'] and result['pe'] > 0:
    implied_roe = (result['pb'] / result['pe']) * 100
    result['roe'] = round(implied_roe, 2)
```

#### 策略 B：傳統會計公式 (備案)
若策略 A 數據不足，則退回使用傳統會計公式計算。
> **公式**： $ROE = \frac{\text{本期淨利}}{\text{權益總額}} \times 100\% \times \text{年化係數}$

```python
# 程式實作範例
if raw_data['NetIncome'] and raw_data['Equity']:
    current_roe = (raw_data['NetIncome'] / raw_data['Equity']) * 100
    # 假設單季資料，乘以 4 進行簡易年化
    result['roe'] = round(current_roe * 4, 2)
```

### 3.3 獲利能力三率

利用營收作為分母，計算毛利率、營業利益率與淨利率。

*   **毛利率** = $\frac{\text{毛利}}{\text{營收}} \times 100\%$
*   **營業利益率** = $\frac{\text{營業利益}}{\text{營收}} \times 100\%$
*   **淨利率** = $\frac{\text{本期淨利}}{\text{營收}} \times 100\%$

```python
# 程式實作範例
if raw_data['GrossProfit'] and raw_data['Revenue']:
    result['gross_margin'] = round((raw_data['GrossProfit'] / raw_data['Revenue']) * 100, 2)
```

### 3.4 殖利率 (Dividend Yield)

API 的股價與股利位於不同資料集，我們將其結合計算：

> **公式**： $\text{殖利率} = \frac{\text{現金股利總和 (去年)}}{\text{最新收盤價}} \times 100\%$

```python
# 程式實作範例
if cash_div and price > 0:
    result['dividend_yield'] = round((float(cash_div) / price) * 100, 2)
```

## 5. 指標取捨說明 (Limitations)

為了在有限的 API額度內完成 **120 檔股票** 的批次下載，我們針對指標進行了以下取捨：
*   **省略資產負債細項**：暫不計算「流動比率」與「速動比率」，以避免額外呼叫 `TaiwanStockBalanceSheet` (每檔多一次 API call)。
*   **省略成長率**：暫不計算 YoY 成長，因為需要下載去年同期的歷史資料。
*   **專注核心指標**：將資源集中在最影響股價的基本面數據 (ROE, PE, PB, 三率)。
*   **ETF 指標**：ETF 無 ROE、負債比等公司型指標，**改採專用評分模型 (詳見下方)**。

## 6. ETF 專屬評分邏輯 (New)

針對 ETF (00開頭代號)，系統採用獨立的評分權重，以反映其商品特性：

1.  **殖利率 (Dividend Yield) - 權重 70%**
    *   ETF 投資人主要訴求為配息收益。
    *   評分：>5% (7分以上)，<3% (低分)。

2.  **股價淨值比 (P/B Ratio) - 權重 30%**
    *   用以衡量 ETF 目前價格相對於淨值（成分股總價值）的折溢價狀況。
    *   評分：<1 (折價/便宜，高分)，>1.5 (溢價/偏貴，低分)。

> **注意**：一般個股依然沿用 ROE (40%) + PE (30%) + PB (15%) + 負債比 (15%) 的標準評分模型。
