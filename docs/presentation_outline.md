# 台股智選系統 - 專案報告/簡報大綱建議

這份大綱旨在協助您向同學或評審介紹此專案的開發過程。除了您提到的「資料下載」、「函式庫」、「介面操作」外，建議加入**「系統架構」**與**「核心邏輯」**，展現程式設計的深度。

---

## 1. 專案動機與目標 (Why & What)
*   **動機**：台股標的眾多 (2000+)，一般人難以逐一研究財報。
*   **目標**：開發一個自動化工具，將複雜的財務數據轉換為簡單的「0-10 分」評分，並提供視覺化選股介面。
*   **解決痛點**：節省查找財報的時間，提供客觀的選股依據。

## 2. 技術架構與工具 (Technology Stack)
*   **核心語言**：Python 3.10+
*   **介面框架 (UI)**：**Streamlit**
    *   *為什麼選 Streamlit？* 快速將 Python 腳本轉換為網頁應用 (Web App)，適合數據分析專案，內建豐富的互動元件 (Slider, Selectbox)。
*   **資料處理**：
    *   **Pandas**：處理表格資料、計算財務指標 (ROE, PE, MA 等)。
    *   **NumPy**：數值運算處理。
*   **資料來源 (Data Source)**：
    *   **FinMind API**：取得台灣股市的即時股價、財報數據。
    *   **TWSE/TPEX Open API**：取得股票列表與產業分類。
*   **AI 整合**：
    *   **OpenAI API**：自然語言解析 (將口語轉為篩選條件)。

## 3. 資料流與系統設計 (System Architecture) 🌟 *加分重點*
*   **Offline-First 設計 (離線優先)**：
    *   *挑戰*：API 呼叫有次數限制且速度慢，即時抓取會讓網頁卡頓。
    *   *解法*：設計「快取機制」。先透過腳本下載資料，清洗並計算好指標，儲存為 `robust_indicators_data.csv`。
    *   *優點*：網頁載入極快，不依賴即時網路請求，提升使用者體驗。
*   **模組化設計 (Project Structure)**：
    *   `main.py`：程式入口與首頁。
    *   `pages/`：利用 Streamlit 的多頁面功能管理不同功能 (搜尋、篩選、排名)。
    *   `src/`：封裝核心邏輯。
        *   `data_fetcher.py`：負責資料抓取與快取讀取。
        *   `stock_analyzer.py`：負責「評分演算法」邏輯。

## 4. 核心演算法：評分系統 (The "Brain") 🌟 *技術亮點*
*   **指標選取**：從眾多財報數據中，精選出 **11 項關鍵指標** (ROE, PE, PB, 殖利率等)。
*   **加權評分邏輯**：
    *   不是所有指標都一樣重要。
    *   **一般股票**：著重獲利 (ROE 40%) 與 估值 (PE 30%)。
    *   **ETF**：自動切換邏輯，著重 現金流 (殖利率 80% + 配息年數 20%)。
*   **評分標準化**：將不同單位的數據 (%, 倍數, 元) 全部轉換為 0-10 分的標準分數，方便排名比較。

## 6. 遇到的困難與解決 (Challenges & Solutions)
*   **資料缺漏問題**：有些公司財報延遲或缺值 (NaN) 怎麼辦？
    *   *解法*：即使缺值也不讓程式崩潰，並在介面上標示 "N/A"。
*   **UI/UX 優化**：Streamlit 原生介面較陽春。
    *   *解法*：撰寫自訂 CSS (`src/styles.py`)，隱藏預設選單，設計卡片式排版 (Glarity 風格)，提升專業感。

## 7. 未來展望 (Future Work)
*   **資料庫遷移**：從 CSV 升級為 SQLite 或 MySQL 資料庫，支援更多歷史數據。
*   **使用者系統**：加入登入功能，讓使用者儲存自己的「關注清單」。
*   **更多 AI 功能**：導入 LLM 閱讀財報新聞，提供質化分析。
