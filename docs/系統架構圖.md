## 資料流程圖

```mermaid
sequenceDiagram
    participant U as 使用者
    participant S as Streamlit UI
    participant A as stock_analyzer
    participant F as finmind_api
    participant D as 資料快取
    participant API as FinMind API

    U->>S: 輸入股票代號
    S->>A: analyze_stock()
    A->>F: load_robust_data()
    
    alt 快取存在
        F->>D: 讀取 CSV
        D-->>F: 回傳資料
    else 快取不存在
        F->>API: fetch_indicators_full()
        API-->>F: 回傳財務資料
        F->>D: 儲存快取
    end
    
    F-->>A: 回傳股票資料
    A->>A: calculate_score()
    A-->>S: 回傳分析結果
    S-->>U: 顯示評分與雷達圖
```
