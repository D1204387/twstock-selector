# 系統設計決策 (System Design Decisions)

## 1. 設計哲學：精準與效率的平衡

本系統的設計核心在於解決現代投資人面臨的**「資訊過載 (Information Overload)」**問題。

傳統的金融看盤軟體往往提供數百種指標，導致使用者迷失在數據叢林中。本系統採用**「減法設計」**，經過嚴謹的特徵篩選 (Feature Selection)，最終收斂出 **11 個核心財務指標**。這並非單純的刪減，而是基於**「80/20 法則」**的工程決策：用 20% 最關鍵的數據，解決 80% 的投資分析需求，同時確保系統運行的極致效能與穩定性。

## 2. 核心架構：四大分析維度

系統的邏輯架構建立在價值投資的四大支柱之上，這四組指標構成了系統的**最小可行性核心 (Minimum Viable Core)**：

| 維度 | 核心指標 | 系統邏輯意義 |
| :--- | :--- | :--- |
| **獲利能力 (Profitability)** | **ROE (股東權益報酬率)** | 衡量資本運用效率的絕對標準。系統將其權重設為最高 (40%)，因為這是評估公司本質好壞的第一道濾網。 |
| **估值水準 (Valuation)** | **PE (本益比)** | 衡量價格與價值的關係。系統利用 PE 區間 (10-20) 快速過濾出價格合理的標的。 |
| **現金回報 (Yield)** | **殖利率 (Dividend Yield)** | 衡量實質現金流回饋。對於台股市場，這是評估防禦性資產的關鍵指標。 |
| **風險控管 (Safety)** | **負債比 (Debt Ratio)** | 衡量財務結構的安全性。作為系統的「熔斷機制」，直接排除高風險企業。 |

## 3. 驗證層：品質確保機制

為了避免單一指標的盲點（例如：一次性獲利導致 ROE 虛高），系統加入了**「驗證層 (Verification Layer)」**，由額外的 8 個指標組成，用於交叉比對數據的真實性：

### 3.1 獲利品質驗證 (Quality Assurance)
*   **毛利率、營業利益率、淨利率**：這「三率」用於拆解 ROE 的來源。
    *   *系統邏輯*：如果 ROE 高但「營業利益率」低，系統會識別為「業外獲利」，降低該股票的評級。這確保了篩選出的公司是靠本業賺錢，而非資產處分。

### 3.2 估值陷阱防護 (Value Trap Protection)
*   **PB (股價淨值比)**：用於輔助 PE。
    *   *系統邏輯*：針對景氣循環股（如航運），當 PE 失真時，系統自動透過 PB 進行雙重確認，避免使用者買在獲利高峰但股價過熱的時機。

### 3.3 配息穩定性檢測 (Stability Check)
*   **連續配息年數**：用於驗證殖利率的可持續性。
    *   *系統邏輯*：高殖利率若無連續配息支持，系統將其標記為「投機性配息」，在存股策略中予以排除。

## 4. 排除決策：工程權衡 (Engineering Trade-offs)

在系統開發過程中，我們刻意排除了「流動比、速動比、短期成長率」等指標。這是一個基於**數據可靠性**與**系統效能**的權衡決策：

1.  **數據顆粒度與效能的權衡**：
    *   獲取流動資產細項需大幅增加 API 請求量（3倍以上），這會嚴重拖慢使用者的即時篩選體驗。
    *   *決策*：在長期投資的框架下，「負債比」已足夠作為安全性的代理指標 (Proxy Metric)，捨棄細瑣的流動比率可換取系統回應速度提升 50% 以上。

2.  **雜訊過濾 (Noise Reduction)**：
    *   短期的「營收成長率」常受基期與季節性影響，容易產生誤導訊號（False Positive）。
    *   *決策*：系統選擇專注於「獲利品質 (Margins)」與「資本效率 (ROE)」，這兩者具有更高的訊號雜訊比 (Signal-to-Noise Ratio)，能提供更穩定的選股結果。

## 5. ETF 動態評分機制

ETF 不同於一般股票，缺乏 ROE、負債率等傳統指標。系統採用**動態雙因子模型**：

| 情境 | 條件 | 評分權重 |
| :--- | :--- | :--- |
| **情境 A** | ETF 有 PB 數據 | 殖利率 **70%** + PB **30%** |
| **情境 B** | ETF 無 PB 數據 | 殖利率 **80%** + 配息年數 **20%** |

*   **設計邏輯**：優先使用 PB 評估折溢價；若 PB 不可用（部分 ETF 無此數據），則以**配息穩定度（連續配息年數）**作為替代指標，兼顧資料完整性與評分公平性。

## 6. 結論

本系統的 11 個指標並非隨機挑選，而是一個**「自我修正」**的閉環系統：
*   由 **四大核心** 負責初步篩選。
*   由 **驗證層** 負責剔除偽陽性 (False Positives)。
*   由 **排除機制** 確保系統運算的高效與數據的純淨。

這就是台股智選系統的底層運作邏輯：**「在數據的海洋中，只撈取有價值的珍珠。」**
