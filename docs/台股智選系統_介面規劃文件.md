## 📚 指標說明中心

### 估值指標

#### 本益比 (PE Ratio)
```
公式：股價 ÷ 每股盈餘 (EPS)
意義：投資回本需要幾年
判斷：
  • < 10：可能被低估
  • 10-20：合理區間
  • > 20：可能被高估
  • < 0：公司虧損
注意：不同產業標準不同，科技股通常較高
```

#### 股價淨值比 (PB Ratio)
```
公式：股價 ÷ 每股淨值
意義：股價相對於帳面價值
判斷：
  • < 1：股價低於淨值（破淨）
  • 1-2：合理區間
  • > 3：可能偏貴
注意：資產型公司（如金融、營建）較適用
```

### 股息指標

#### 殖利率 (Dividend Yield) ⭐重要
```
公式：(預估配息 ÷ 當前股價) × 100%
意義：投資報酬率（現金流角度）
判斷：
  • ≥ 7%：優質高息
  • 6-7%：達標（李博士標準）
  • 4-6%：尚可
  • < 4%：偏低
注意：太高可能是股價崩跌造成，要檢查原因
```

#### 連續配息年數
```
意義：配息穩定性指標
判斷：
  • ≥ 10年：非常穩定
  • ≥ 5年：穩定（基本要求）
  • < 3年：穩定性不足
注意：景氣循環股可能中斷配息
```

#### 配息率 (Payout Ratio)
```
公式：(配息 ÷ EPS) × 100%
意義：盈餘分配給股東的比例
判斷：
  • 50-80%：健康範圍
  • > 100%：配息超過盈餘（不健康）
  • < 30%：公司保留較多資金
```

### 獲利指標

#### ROE 股東權益報酬率 ⭐最重要
```
公式：淨利 ÷ 股東權益 × 100%
意義：公司用股東的錢賺錢的效率
判斷：
  • ≥ 20%：優秀
  • 15-20%：良好
  • 10-15%：普通
  • < 10%：較差
巴菲特標準：長期維持 > 15%
```

#### ROA 資產報酬率
```
公式：淨利 ÷ 總資產 × 100%
意義：公司運用全部資產的效率
判斷：
  • ≥ 10%：優秀
  • 5-10%：良好
  • < 5%：較差
注意：資本密集產業通常較低
```

#### 稅後淨利率
```
公式：淨利 ÷ 營收 × 100%
意義：每100元營收能賺多少
判斷：
  • ≥ 15%：優秀
  • 10-15%：良好
  • 5-10%：普通
  • < 5%：薄利
```

### 財務安全指標

#### 負債比率 ⭐重要
```
公式：總負債 ÷ 總資產 × 100%
意義：財務槓桿風險
判斷：
  • < 40%：非常安全
  • 40-50%：安全
  • 50-60%：尚可
  • > 60%：需注意（李博士上限）
例外：金融業負債率通常 > 90%，屬正常
```

#### 流動比率
```
公式：流動資產 ÷ 流動負債 × 100%
意義：短期償債能力
判斷：
  • ≥ 200%：非常安全
  • 150-200%：安全
  • 100-150%：尚可
  • < 100%：可能有流動性風險
```

#### 速動比率
```
公式：(流動資產-存貨) ÷ 流動負債 × 100%
意義：扣除存貨後的償債能力
判斷：
  • ≥ 100%：安全
  • 80-100%：尚可
  • < 80%：需注意
```

### 成長指標

#### 營收成長率
```
公式：(今年營收-去年營收) ÷ 去年營收 × 100%
意義：公司業務擴張速度
判斷：
  • ≥ 20%：高成長
  • 10-20%：穩健成長
  • 0-10%：微幅成長
  • < 0%：衰退
```

#### EPS 成長率
```
公式：(今年EPS-去年EPS) ÷ 去年EPS × 100%
意義：盈餘成長速度
判斷：
  • ≥ 25%：高成長
  • 15-25%：良好成長
  • 0-15%：微幅成長
  • < 0%：衰退
```

### 籌碼面指標

#### 大戶持股變化
```
定義：
  • 股價 ≥ 100元：400張以上為大戶
  • 股價 < 100元：1000張以上為大戶
意義：法人、主力的動向
判斷：
  • 連續增加：籌碼集中，看好
  • 連續減少：籌碼鬆動，保守
資料來源：集保戶股權分散表（每週更新）
```

#### 股東人數變化
```
意義：籌碼集中或分散
判斷：
  • 減少：籌碼集中（大戶吃貨）
  • 增加：籌碼分散（大戶出貨）
搭配：大戶增加 + 人數減少 = 最佳訊號
```
