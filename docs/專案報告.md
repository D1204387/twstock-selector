# 台股智選系統 專案報告

> **Python 期末專案 | 2025**

---

## 1. 專案目標

解決台股投資人面臨的「資訊過載」問題，開發智慧選股系統。

| 目標 | 說明 |
|------|------|
| 真實數據 | 使用 FinMind API 真實財務資料 |
| 離線優先 | Offline-First 架構，零延遲瀏覽 |
| AI 選股 | 自然語言查詢選股 |

---

## 2. 系統架構

```
Streamlit Web App
├── 🔍 搜尋  │  📊 策略篩選  │  🏆 排名分析  │  🤖 AI選股
├── stock_analyzer / stock_screener / ai_query
└── FinMind API → robust_indicators_data.csv (本地快取)
```

---

## 3. 資料涵蓋

**120 檔**精選標的（涵蓋台股 85% 市值）：
- 台灣 50 成分股 (50 檔)
- 中型 100 精選 (50 檔)
- 熱門 ETF (10 檔)
- 補充熱門股 (10 檔)

---

## 4. 評分系統

**一般個股**

| 指標 | 權重 |
|------|------|
| ROE | 40% |
| PE | 30% |
| PB | 15% |
| 負債率 | 15% |

**ETF**：殖利率 80% + 配息年數 20%

---

## 5. 內建策略

| 策略 | 核心條件 |
|------|---------|
| 🚀 成長股 | 高 ROE、高淨利率 |
| 💎 價值股 | 低 PE、低 PB |
| 💰 高股息 | 高殖利率、穩定配息 |
| ⭐ 優質股 | 財務穩健、低負債 |

---

## 6. 技術應用

| 技術 | 應用 |
|------|------|
| Pandas | 向量化運算、資料處理 |
| Streamlit | Pure Python Web UI |
| Requests | API 速率限制、自動重試 |

---

## 7. 結語

本系統專注於分析公司財務體質，幫助投資人找到值得長期持有的好公司。

---

## 8. 依賴套件

`streamlit` / `pandas` / `numpy` / `requests` / `plotly`
